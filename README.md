# 📌 Фиксация чатов

Плагин для **AyuGram / exteraGram**, который позволяет оставлять чаты на выбранных местах в списке.

Если чат находится на седьмом месте, после нового сообщения он остаётся седьмым. Превью последнего сообщения и счётчик непрочитанных продолжают обновляться.

**Версия: 0.1.1 · Статус: бета**

[Файл плагина — chat_fix.plugin](./chat_fix.plugin)

## Возможности

- Фиксация одного или нескольких чатов на текущих местах.
- Режим «Зафиксировать все» для сохранения порядка всего списка.
- Перемещение зафиксированных чатов за ручку **≡**.
- Булавка рядом со временем у отдельно зафиксированных чатов.
- Сохранение позиций после перезапуска приложения.
- Отдельный порядок для каждой папки и аккаунта.
- Встроенная диагностика с копированием отчёта.

## Режимы фиксации

| Поведение | Отдельные чаты | «Зафиксировать все» |
| --- | --- | --- |
| Что сохраняется | Места выбранных чатов | Порядок всех чатов |
| Остальные чаты | Продолжают сортироваться по активности в свободных местах | Сохраняют свой порядок |
| Новые чаты | Следуют обычной сортировке в свободных местах | Добавляются в конец сохранённого списка |
| Дополнительные булавки | Показываются у отдельно зафиксированных чатов | Скрыты |
| Булавки обычных закреплений Telegram | Сохраняются | Сохраняются |

Порядок действует локально в этом приложении и не синхронизируется с другими клиентами Telegram. Фиксация плагина не изменяет обычные закрепления Telegram.

## Установка

1. Скачай [chat_fix.plugin](./chat_fix.plugin). На странице файла в GitHub используй кнопку **Download raw file**.
2. Установи файл через встроенный менеджер плагинов AyuGram / exteraGram.
3. Включи «Фиксацию чатов» в разделе плагинов.

При обновлении установи новый файл поверх предыдущей версии.

## Использование

### Зафиксировать отдельные чаты

1. Зажми нужный чат.
2. При необходимости выдели ещё несколько чатов.
3. Открой меню **⋮** и выбери **«Зафиксировать чаты»**.

Чаты сохранят текущие позиции. Рядом со временем появится значок булавки.

Чтобы снять фиксацию, выдели нужные чаты и выбери **⋮ → «Снять фиксацию чатов»**.

### Зафиксировать весь список

Открой настройки плагина и включи **«Зафиксировать все»**.

Переключатель действует для текущего аккаунта. В каждой папке сохраняется собственный порядок. Дополнительные булавки плагина скрываются, а значки обычных закреплений Telegram остаются.

Пока общий режим включён, отдельную фиксацию через меню изменить нельзя. После его выключения снова применяются ранее сохранённые отдельные фиксации.

### Изменить порядок

1. Выдели чат, чтобы открыть режим выбора.
2. Зажми ручку **≡** у зафиксированного чата.
3. Перетащи чат на нужное место.

В режиме «Зафиксировать все» перемещать можно любой чат. Новый порядок сохраняется после перезапуска.

### Сбросить фиксацию

В настройках плагина нажми **«Снять всю фиксацию»**. Это удалит отдельные фиксации и сохранённый порядок, а также выключит общий режим для текущего аккаунта.

Если просто отключить плагин, приложение вернётся к обычной сортировке, а сохранённые настройки фиксации останутся для следующего включения.

## Совместимость и статус

**0.1.1 — бета-версия.**

| Требование | Значение |
| --- | --- |
| Клиент | AyuGram / exteraGram с поддержкой Python-плагинов |
| Версия приложения в метаданных плагина | `>=13.1.1` |
| SDK плагинов | `>=1.4.4.3` |

Совместимость зависит от внутренних методов конкретной сборки клиента. Логика позиций проверена локально; работа меню, значков и перетаскивания требует проверки на устройстве.

Фиксация предназначена для основного списка чатов, папок и архива. Поиск и специальные экраны выбора чатов не поддерживаются. Если часть чатов временно отсутствует в списке, их отображаемые позиции могут сдвигаться; сохранённые места при этом не перезаписываются.

## Сообщить об ошибке

Открой настройки плагина → **«Диагностика» → «Копировать»**.

В обращении к автору или в Issue приложи:

- версию плагина и точную версию AyuGram / exteraGram;
- шаги для повторения ошибки;
- ожидаемое и фактическое поведение;
- отчёт диагностики, а при ошибке включения — текст исключения из клиента;
- при необходимости скриншот или запись экрана.
